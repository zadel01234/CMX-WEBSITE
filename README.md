# CMX Connect Ibadan — Routed

React + Vite + TypeScript project with `react-router-dom` routing.

## Setup

```bash
# 1. Install dependencies (required after unzipping)
npm install

# 2. Start dev server
npm run dev
```

> The project runs on http://localhost:3000

## Routes

| URL           | Page       |
|---------------|------------|
| `/`           | Home       |
| `/about`      | About      |
| `/speakers`   | Speakers   |
| `/highlights` | Highlights |
